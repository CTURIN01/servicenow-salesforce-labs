# ServiceNow Incident Workflow Notes

## Objective
Practice core ITSM incident management concepts in a ServiceNow Personal Developer Instance.

## Environment

## Steps to Complete
- [ ] Spin up Personal Developer Instance

- [ ] Build notification trigger for P1 incident creation and resolution
- [ ] Document findings and screenshots

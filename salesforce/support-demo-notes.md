# Salesforce Support Demo Org Notes

## Objective
Use a Salesforce Developer Edition org to model a small customer support process.

## Environment
- Salesforce Developer Edition org (free from developer.salesforce.com)

## Steps to Complete
- [ ] Create Developer Edition org
- [ ] Configure custom object or extend Cases with additional fields
- [ ] Add validation rules for required fields
- [ ] Build reports tracking open cases by priority and owner
- [ ] Build a dashboard from those reports
- [ ] Build a simple Flow for follow-up task automation
- [ ] Document findings and screenshots
